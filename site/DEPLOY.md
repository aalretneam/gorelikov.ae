# Как выложить Расписалку на gorelikov.ae за 10 минут

Сайт полностью статический — три файла из папки `site/`:

- `index.html` — весь сайт (лендинг + редактор)
- `og.png` — картинка для превью в соцсетях/мессенджерах
- `og.html` — исходник баннера (на сервер заливать не обязательно)

## Перед выкладкой — 2 обязательные правки в index.html

1. **Донат.** Найди в `index.html` строку:
   ```
   donateUrl: "https://pay.cloudtips.ru/p/REPLACE_ME",
   ```
   Создай страницу на [pay.cloudtips.ru](https://pay.cloudtips.ru) (или Boosty / Buy Me a Coffee / Tribute)
   и вставь свою ссылку.

2. **Яндекс.Метрика** (рекомендую — покажет охват, источники, георазбивку).
   Зарегистрируй счётчик на [metrika.yandex.ru](https://metrika.yandex.ru), скопируй код
   и вставь вместо строки `<!-- METRIKA_PLACEHOLDER -->`.
   Встроенный счётчик counterapi.com работает и без этого, но Метрика гораздо подробнее.

## Вариант А: Cloudflare Pages (рекомендую — бесплатно, быстро, CDN)

1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com).
2. Workers & Pages → Create → Pages → **Upload assets** → перетащи папку `site/`.
3. Проект получит адрес вида `raspisalka.pages.dev` — проверь, что всё работает.
4. Подключи домен: в проекте Pages → Custom domains → добавь `gorelikov.ae`.
   Cloudflare покажет, какие DNS-записи прописать у регистратора домена
   (проще всего перевести DNS домена на Cloudflare — они проведут за руку).
5. HTTPS включится автоматически.

## Вариант Б: GitHub Pages

1. Создай репозиторий, положи содержимое `site/` в корень.
2. Settings → Pages → Deploy from branch → `main`, папка `/`.
3. В Settings → Pages → Custom domain впиши `gorelikov.ae`.
4. У регистратора домена добавь A-записи GitHub Pages:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   и CNAME `www` → `<твой-логин>.github.io`.

## Вариант В: любой хостинг с FTP

Просто залей `index.html` и `og.png` в корень сайта. Всё.

## Где смотреть охват

- Живой счётчик: https://counterapi.com/stats/gorelikov-ae-raspisalka/visit/site
  (там же `download/site` — скачивания и `share/site` — шеринги).
- Яндекс.Метрика — после установки кода.

## Идеи для запуска (чтобы дать охват)

- Скинь ссылку в школьные/студенческие чаты 1 сентября и перед семестром — пик спроса.
- Запость примеры расписаний (Y2K, неон, тетрадь) в TikTok/Reels/Shorts:
  «собираю расписание за 60 секунд» — формат идеально виральный.
- Ватермарка «расписалка · gorelikov.ae» на каждой скачанной картинке
  уже работает как бесплатная реклама.
- Шеринг-ссылки: когда один человек кидает расписание одноклассникам,
  все они попадают на сайт.
