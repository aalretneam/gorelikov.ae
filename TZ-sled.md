## 2. Главная новая сущность — След

Создать `src/shared/trace.ts`.

```ts
type RoomId =
  | "hub"
  | "field"
  | "mosaic"
  | "machine"
  | "want"
  | "behind"

type Trace = {
  v: 1
  id: string
  started: number
  ms: number
  rooms: RoomId[]
  clicks: number
  moves: number
  pauses: number
  returns: number
  continues: number
  stops: number
  last: RoomId
  notes: string[]
}

type TraceEvent =
  | { type: "click" }
  | { type: "move" }
  | { type: "pause" }
  | { type: "stop" }
  | { type: "continue" }
  | { type: "note"; label: string }
```

Хранение: `localStorage`, ключ `ag-trace`.

### Правила

- `id` — локальный стабильный идентификатор, без отправки наружу; нужен имени PNG;
- `started` — первый вход в этом браузере (или после сброса битого JSON);
- `ms` — только видимое время;
- `rooms` — порядок **первого** входа; повтор не дублирует;
- `clicks` — один `pointerdown`;
- `moves` — не чаще 4 Гц;
- `pauses` — пауза > 2.2 с после активности **пока visible**, как в `machine/session.ts`;
- `returns` — вход в уже открытую комнату (`rooms` уже содержит id);
- `continues` — дверь / порог / continue;
- `stops` — длинный простой **или** уход вкладки в background (не вместе с pause на том же hide);
- `last` — последняя комната;
- `notes` — редкие ярлыки поведения, не полный лог; кольцо, максимум 8; cooldown; один ярлык не подряд.

### API

```ts
load(): Trace
save(trace: Trace): void
record(event: TraceEvent): Trace
snapshot(): Trace
flush(): void
enter(room: RoomId): Trace
```

`enter` сам отличает первый вход от `return`.

Добровольно, не обязательно в первом PR: `bind(room)` — один раз вешает pointer/visibility, чтобы шесть `main.ts` не копипастили.

События типизировать. Не разрешать произвольные поля в JSON.

### Надёжность

- битый JSON → молча создать новый Trace;
- недоступный localStorage → memory fallback;
- private mode не должен ломать комнату;
- не писать localStorage на каждый кадр и не на каждый `pointermove`;
- изменения копить в памяти;
- `flush` на `visibilitychange` и `pagehide`;
- не полагаться на `unload`;
- ограничить размер сохранённого JSON;
- при обновлении `v` — безопасный migration/fallback (незнакомая версия = новый Trace, старый не читать наугад).

### Время

`ms` считать только по видимости. При `hidden` закрывать интервал; при возврате открывать новый. Не допускать двойных таймеров. Возврат из background не должен создавать вторую пару listeners.

## 20. Новые критерии перед merge

### Драматургия

- Манифест один раз за визит.
- Манифест не блокирует первый жест.
- Двери не выглядят меню.

### След

- Повреждённый JSON не ломает приложение.
- localStorage unavailable → memory fallback.
- visibilitychange/pagehide сохраняют видимое время.
- Нет записи localStorage на каждый pointermove.
- `rooms` сохраняет первый порядок входа.
- `returns` не путается с первым входом.
- notes ограничены и имеют cooldown.
- миграция `v` безопасна.
- hide не двойнит pause+stop.

### Машина

- Внутренний Session работает независимо.
- Общий След не сбрасывает телеметрию.
- Карточка использует реальные числа визита.

### Артефакт

- Тонкий визит не получает фальшивых данных.
- Два Trace дают разные изображения.
- Один Trace даёт одинаковый результат после reload.
- PNG имеет корректное имя.
- Web Share — progressive enhancement.
- Кнопка не похожа на CTA.

### Mobile

- Permission не обязателен.
- Нет hover-зависимого пути.
- Основные действия доступны touch.
- Vibration не обязательна.

### Background

- RAF не жжёт GPU в background.
- WebAudio mute/pause в background.
- Возврат не создаёт двойных таймеров/listeners.
