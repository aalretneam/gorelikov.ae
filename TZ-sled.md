## Одна сущность: След

Новый модуль `src/shared/trace.ts` (localStorage, ключ `ag-trace`, версия в JSON).

Пишет **этот** визит + мягко копит жизнь вкладки. Не публичная статистика, не cookie-баннер, не «мы собираем данные».

```ts
type RoomId = "hub" | "field" | "mosaic" | "machine" | "want" | "behind"

type Trace = {
  v: 1
  id: string          // раз за браузер, как session.id машины
  started: number     // Date.now первого захода
  ms: number          // сумма видимого времени (складывать PresenceClock при hide/unload)
  rooms: RoomId[]     // порядок первого входа
  clicks: number
  moves: number       // прореживать, не каждый pointermove
  pauses: number      // тишина > ~2.2 с после активности (как Session.tick)
  returns: number     // повторный вход в уже открытую комнату
  continues: number   // дверь / порог / «продолжить» в машине
  stops: number       // длинный простой или visibility hidden
  last: RoomId
  notes: string[]     // редкие ярлыки машины: "слишком быстро", "ты остановился"…
}
```

Правила записи:

- один `pointerdown` = click; move — не чаще 4 Гц;
- пауза — та же логика, что `src/machine/session.ts` (2.2 с);
- `returns`: зашёл в комнату, которая уже в `rooms`;
- `notes` — не лог на весь экран. Максимум несколько, с кулдауном;
- private mode / отказ storage — молча работать в памяти, артефакт всё равно собрать за сессию.

Машина: при `session.mark` / `pauses` **дублировать** в След. Не выкидывать её внутренний `Session` — он крутит телеметрию кадра.

Хаб: `markOpened` оставить. След знает порядок; шрам порога — по-прежнему «бывал».

## Невидимый наблюдатель

`src/shared/observer.ts` — не страница и не модалка.

Редкие шёпоты (занятость как у `whisper.busy`, не два сразу). Пороги по Следу, не по таймеру «каждые N секунд».

Примеры, не произносить пачкой и не на первой секунде:

- после ~20 с в любой комнате: `внимание` + живой процент (как телеметрия машины, тот же тон);
- пауза: `ты остановился`;
- быстрые повторные клики: `слишком быстро`;
- return в комнату: `ты вернулся`;
- выдох в желании / дверь / continue: `ты продолжил`;
- в «за плечами», если След уже толстый: не «мы собираем данные», а портрет (см. комнату).

Никогда: cookie, GDPR-простыня, «аналитика», имя художника.

Машина уже говорит `ты наблюдаешь.` / `система знает.` — наблюдатель на других экранах должен быть **тише** и реже, иначе все комнаты станут машиной.

## Приоритеты внедрения

Семь пунктов рецензии = семь фаз. Каждая фаза — отдельный PR в `artgorelikov`. Не смешивать «артефакт» с «tilt».

Критерий фазы: человек без пояснения **чувствует** новый слой, а не читает его в ТЗ.

### Фаза 1 — драматургия без меню 🔴

Связать шесть экранов одной рамкой. Самый дешёвый смысл.

**Хаб `/`**

- Один раз за визит, до нынешних семи строк, два такта шёпота (держать ~как сейчас +5 с):
  1. `Ты здесь не для того, чтобы смотреть.`
  2. `Ты здесь, чтобы оставить след.`
- Потом существующие строки лабиринта. Не подпись под логотипом, не онбординг.
- Слова порогов не менять: `остаться / собрать / смотреть / хотеть / уже` — это и есть 01…06 без цифр.
- Если открыты все пять — в финале визита на хабе один раз едва: `ты уже был`.

**Склейка**

- Title комнат оставить одно слово (`поле`, `мозаика`, `хотеть`…).
- Не рисовать «02 — двигаться» на экране.

**Файлы:** `src/hub/main.ts`, тексты дверей в `field.html` / `machine.html`.

**Приёмка:** новый человек за 90 с понимает, что это не галерея пяти демо, и что от него ждут жеста, не просмотра.

### Фаза 2 — сквозной След 🔴

Инфраструктура. Без неё 3, 4, 9, 10, 13 не живут.

- `src/shared/trace.ts`: load/save, `record(event)`, `snapshot()`.

- Хаб: шрам порога по-прежнему из `ag-opened`; След параллельно.

**Приёмка:** открыть поле → машину → желание, обновить хаб, в консоли/снимке Следа есть три комнаты, клики и ms. Инкогнито не падает.

### Фаза 3 — машина как центр 🔴

Не рефакторить 9 состояний и шейдер.

**Снаружи**

- Дверь: новые реплики (фаза 1).
- Телеметрия: проценты пусть **дышат от Следа** (внимание растёт с ms, ввод человека — с clicks), не только от локального `att/cur`. Плавный lerp, как сейчас.
- На `trace` / `complete`: карточка уже рисуется из `session.seed`. Добавить в colophon **тихие числа этого визита** (время, жесты, паузы) — тем же моноширинным языком, что таймер. Не «спасибо за регистрацию».

**Наблюдатель**

- В observation/interference машина и так говорит. Не дублировать. Наблюдатель — на других комнатах.
- Мысль `ты был частью этого.` уже есть в mirror — оставить. Это ось проекта.

**Запрет:** не вставлять в машину навбар, не выносить телеметрию на хаб постоянно.

**Приёмка:** после пары минут в поле проценты «ввод человека» на машине не стартуют с 12% как будто визит только что начался.

### Фаза 4 — финальный артефакт 🔴

Не страница «спасибо».

**Где:** комната «за плечами», когда След.rooms.length ≥ 2 **или** человек смотрит **назад** достаточно долго. Если зашли только сюда — артефакт тонкий, без фальшивых цифр.
