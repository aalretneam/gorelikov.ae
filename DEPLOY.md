# Деплой Расписалки на VPS через GitHub

Сайт статический. На сервер уходит содержимое `site/` в `/var/www/gorelikov.ae`.
Пуш в `main` сам выкладывает через GitHub Actions.

VPS тот же, что Palma / QuestQuest: **`208.76.221.48`**. Отдельный nginx-vhost, чужие сайты не трогаем.

## 1. DNS

У регистратора `gorelikov.ae`:

| Тип | Имя | Значение |
|-----|-----|----------|
| A | `@` | `208.76.221.48` |
| A | `www` | `208.76.221.48` |

Парковочные ANAME/CNAME на DonDominio — удалить, иначе корень будет скакать.

## 2. GitHub-репозиторий и секреты

Репозиторий: этот проект. Secrets (Settings → Secrets and variables → Actions):

| Secret | Значение |
|--------|----------|
| `VPS_HOST` | `208.76.221.48` |
| `VPS_USER` | `root` |
| `VPS_SSH_KEY` | приватный ключ деплоя (целиком, включая `BEGIN`/`END`) |

Публичную пару ключа добавь на VPS в `/root/.ssh/authorized_keys`.

С Mac, один раз:

```bash
ssh-keygen -t ed25519 -f ~/.ssh/gorelikov_deploy -N "" -C "gorelikov-github-actions"
ssh-copy-id -i ~/.ssh/gorelikov_deploy.pub root@208.76.221.48
# приватный ~/.ssh/gorelikov_deploy — в секрет VPS_SSH_KEY
```

## 3. Первый раз на VPS

Когда репозиторий уже на GitHub:

```bash
ssh root@208.76.221.48
git clone git@github.com:USER/gorelikov.ae.git /opt/gorelikov.ae
bash /opt/gorelikov.ae/deploy/install.sh
bash /opt/gorelikov.ae/deploy/setup-ssl.sh
```

`install.sh` копирует `site/` в `/var/www/gorelikov.ae` и включает nginx.
`setup-ssl.sh` выпускает Let's Encrypt (нужны верные A-записи и открытые 80/443).

## 4. Дальше

Пуш в `main` → workflow **Deploy to VPS** → rsync в `/opt/gorelikov.ae` → `install.sh`.

Короткие ссылки `https://gorelikov.ae/s/k4m2np8q` — gzip в `/var/lib/raspisalka/` (обычно 200–800 байт, одинаковые расписания не дублируются). Старые длинные `#s=...` открываются как раньше.

Проверка: https://gorelikov.ae/

## Перед продом — донат и Метрика

В `site/js/app.js`, объект `CONFIG`:

1. **Донат.** `donateUrl: ""` — CloudTips / Boosty / Tribute. Пока пусто — кнопка открывает почту `artem@gorelikov.ae`.
2. **Яндекс.Метрика.** Счётчик **112279782** стоит в `site/index.html`. Тег грузится только на `gorelikov.ae` / `www` (www сразу редиректит на канонический хост). С localhost хиты не уходят.

Сайт сам шлёт цели (`reachGoal`). **В кабинете Метрики их всё равно нужно создать вручную** — иначе в отчётах «Цели» будет пусто, хотя события уже летят:

| Идентификатор | Когда | Тип в кабинете |
|---|---|---|
| `editor_open` | открыли редактор | JavaScript-событие |
| `download` | скачали PNG | JavaScript-событие |
| `print` | нажали печать / PDF | JavaScript-событие |
| `share` | поделились ссылкой | JavaScript-событие |
| `schedule_created` | первое готовое расписание в сессии (скачать / печать / ссылка) | JavaScript-событие |
| `donate_open` | открыли окно доната | JavaScript-событие |
| `thanks` | нажали «спасибо» | JavaScript-событие |

Как завести цели (новый кабинет Метрики):

1. Цели → **Добавить цель**.
2. В блоке «Пользовательские события» выбрать **Целевое событие • ex JS-событие**.  
   Не «Клик по кнопке», не «Скачивание файла», не «Параметры», не «Посещение страниц»: код уже шлёт `reachGoal`, визуальный клик ловит только одну кнопку и пропускает карточки стилей, `#edit` и ссылки `/s/…`.
3. Если уже сохранил цель типа «Клик по кнопке» с именем `editor_open` — удали её и создай заново как целевое событие.
4. Заполни три поля и нажми **Добавить цель**. Повтори 7 раз:

| Название цели (по-русски, как удобно) | Условие | Идентификатор |
|---|---|---|
| Открыли редактор | **совпадает** | `editor_open` |
| Скачали PNG | **совпадает** | `download` |
| Печать / PDF | **совпадает** | `print` |
| Поделились ссылкой | **совпадает** | `share` |
| Собрали расписание | **совпадает** | `schedule_created` |
| Открыли донат | **совпадает** | `donate_open` |
| Нажали спасибо | **совпадает** | `thanks` |

Идентификатор — латиница, как в таблице, без пробелов и без кавычек. Условие обязательно **совпадает**, не «содержит» (иначе `download` может пересечься с чем-то ещё). Код на сайт копировать не надо — `reachGoal` уже есть.

Через пару минут открой https://gorelikov.ae/ в режиме инкогнито, нажми «Собрать расписание» и скачай PNG. В Метрике: отчёт «Конверсии» или цель → последние достижения. Если пусто — Adblock или цель с другим идентификатором.

Параметры `theme` и `fmt` у download/print/share видны в отчёте цели → группировка по параметрам. Воронка: визит → `editor_open` → `schedule_created`.

### Кабинет Метрики — что включить

- Часовой пояс **Москва** (или тот, откуда основная аудитория).
- Фильтр роботов: «не учитывать роботов» (по умолчанию обычно включено).
- Свой IP можно исключить в Фильтрах, чтобы не косить статистику при правках.
- Карта кликов и Вебвизор уже включены в коде — в кабинете проверь, что счётчик их принимает (тариф/лимиты).
- Не включай ecommerce: магазина нет.
- Привяжи счётчик к **Яндекс.Вебмастеру** (Вебмастер → Настройки → Привязка Метрики).

Редактор живёт на `#edit`, переходы идут через `history.replaceState` (hashchange не срабатывает). Код сам шлёт `ym(hit)` при входе в редактор и возврате на лендинг.

### Яндекс.Вебмастер (поиск, не Метрика)

Это отдельно от счётчика и нужно для выдачи:

1. [webmaster.yandex.ru](https://webmaster.yandex.ru/) → добавить `https://gorelikov.ae/`.
2. Подтвердить права: мета-тег в `<head>` или файл в `site/` (после деплоя).
3. Отправить sitemap: `https://gorelikov.ae/sitemap.xml` (`robots.txt` уже на него указывает).
4. Главное зеркало: `gorelikov.ae` без www (www редиректит на apex).
5. Регион: Россия. Оригинальные тексты — главная.
6. Проверить индексацию и ошибки обхода.

Код подтверждения Вебмастера в репозиторий не кладём, пока его нет на руках.

Живые цифры на главной: заходы и «создано расписаний» (abacus). Второе растёт один раз за сессию, когда человек сохранил, напечатал или отправил расписание. Это не Метрика — отдельный публичный счётчик.

## Продвижение

Метрика считает, откуда люди и что делают. Сама по себе она сайт не поднимает.

**Поиск (бесплатно, долгий эффект)**

- Вебмастер + sitemap, как выше.
- Запросы: «составить расписание уроков», «красивое расписание на телефон», «шаблон расписания школы», «расписание на обои», «расписание числитель знаменатель».
- На лендинге уже есть title, description, Open Graph, Schema.org. Имеет смысл позже добавить блок FAQ с этими формулировками — Яндекс любит текст, не только конструктор.
- Скорость и мобильная вёрстка уже в плюс. Не закрывать главную от индексации (`/s/` в `robots.txt` закрыт специально — чужие расписания в поиск не должны).

**Вирусный контур продукта (главный канал)**

- Водяной знак «расписалка» на PNG — не выключай по умолчанию.
- Ссылка «кинь другу» и сторис/обои — основной рост к 1 сентября и после каникул.
- Классные чаты Telegram/WhatsApp, родительские чаты, беседы курса.
- Короткие ролики: собрал расписание за 30 секунд → TikTok, Reels, Shorts, VK Клипы, Дзен.
- Посты на Пикабу, VC, DT, тематические паблики «школа / универ / оформление конспектов».

**Каналы, которые стоит завести**

- Telegram-канал или закреп в [@gorelikov](https://t.me/gorelikov): «сделай расписание к 1 сентября».
- Страница во VK (поиск и реклама VK Реклама дешевле Директа на школьниках).
- При желании платная реклама: Яндекс.Директ по запросам выше + РСЯ на «школа, 14–17». Без целей в Метрике Директ почти слепой — сначала заведи цели, потом крути объявления на `schedule_created`.

**Не надо специально**

- Google Analytics «на всякий случай» — аудитория русская, хватит Метрики.
- Ecommerce, колл-трекинг, офлайн-конверсии.
- Покупка ссылок и накрутка поведенческих — Вебмастер это видит, потом вылетите из поиска.
